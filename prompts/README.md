# Prompts

One general entry point and four specialized workflows. Each prompt follows **[AGENTS.md](../AGENTS.md)** and uses the same shared standards.

| Prompt | Use it when… |
| :-- | :-- |
| [**Start a project**](UNIVERSAL-START.md) | You want to design and build any digital product |
| [**Image → web**](IMAGE-REFERENCE-TEST.md) | You have a product image and want a premium web experience |
| [**Build Charlie's website**](BUILD-CHARLIE-WEBSITE.md) | You are developing Charlie Architect's official website |
| [**Review a project**](REVIEW-PROJECT.md) | You need a functional, architectural and UX audit |
| [**Visual calibration**](VISUAL-CALIBRATION-REVIEW.md) | The site looks weaker than a preferred reference |

The general prompt and image-specific prompt are **alternatives**, not instructions that must both run.
