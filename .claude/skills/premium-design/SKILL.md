# Premium Design

When a product image is provided, read docs/IMAGE-TO-EXPERIENCE.md, inspect it directly, and create a visual evidence sheet, non-generic hero, and a visual concept uniquely linked to the product.

1. Read docs/DESIGN-SYSTEM.md and the project brief.
2. Audit brand, user needs, product goals, constraints and existing UI.
3. Propose one primary creative direction with typography, palette, composition, imagery and visual rhythm. Explain why it fits.
4. Translate to real design tokens and reusable UI components. Do not ship default components unchanged.
5. Implement responsive, keyboard-accessible UI and all key states.
6. Inspect and refine mobile, desktop and intermediate widths.
7. Report verification and tradeoffs.
