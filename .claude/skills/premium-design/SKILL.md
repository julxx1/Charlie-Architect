# Visual fidelity protocol

Read `docs/design/VISUAL-FIDELITY-STANDARD.md` and `docs/quality/SCREENSHOT-DESIGN-REVIEW.md` for product images or visual redesigns. Preserve product scale and perceived material depth: real visual hierarchy, readable details, edge construction, coherent shadows and a generous editorial stage. Review screenshots at actual viewport sizes before reporting completion, or mark visual QA NOT VERIFIED.

# Premium Design

When a product image is provided, read docs/design/IMAGE-TO-EXPERIENCE.md, inspect it directly, and create a visual evidence sheet, non-generic hero, and a visual concept uniquely linked to the product.

1. Read docs/design/DESIGN-SYSTEM.md and the project brief.
2. Audit brand, user needs, product goals, constraints and existing UI.
3. Propose one primary creative direction with typography, palette, composition, imagery and visual rhythm. Explain why it fits.
4. Translate to real design tokens and reusable UI components. Do not ship default components unchanged.
5. Implement responsive, keyboard-accessible UI and all key states.
6. Inspect and refine mobile, desktop and intermediate widths.
7. Report verification and tradeoffs.

8. Read `docs/strategy/PRODUCT-INTERACTION-STRATEGY.md`; identify and implement one fitting signature interaction before defaulting to generic sections.
9. Review tactile feedback, focus, spatial origin and narrative restraint with `docs/design/DESIGN-ENGINEERING-CRAFT.md`. Propose genuine concept alternatives only if product direction is ambiguous.

10. Read `docs/strategy/EXPERIENCE-MODE-SELECTION.md` and classify the intended website before UI design. Product photo + premium visual request normally means an editorial showcase, not diagnostic utility.
11. Apply `docs/design/EDITORIAL-ART-DIRECTION.md`; protect product prominence, page-wide contrast, unique storytelling, emotional impact and real exploratory interaction.
12. Run a Creative Director veto before implementation and a visual audit afterwards. Browser screenshots when available; no unmeasured claims.
