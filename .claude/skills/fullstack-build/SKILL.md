# Fullstack Build

1. Read docs/engineering/ENGINEERING.md and inspect repository.
2. Define user flows, scope, data, integrations and minimal architecture.
3. Decide stack based on use cases; explain tradeoffs. Never add libraries solely for prestige.
4. Implement real persistence and authorization where required; do not fake functionality.
5. Build reusable, accessible components, validation, error states and state management.
6. Add relevant tests and run available checks; note missing secrets/integrations.
7. Provide setup, deployment and remaining-issues notes.
